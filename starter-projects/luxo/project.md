## A lamp with a little movement

Inspired by Pixar's Luxo Jr., this 3D-printed robot uses coordinated servo movements to jump and move around. It was demonstrated at Bay Area Maker Faire in 2019.

The project explores expressive robot movement and human–robot interaction, using the ROS JointTrajectoryController stack. Printable parts and code are available in the repository.
